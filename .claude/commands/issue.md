# GitHub Issue 생성

GitHub 이슈를 대화형으로 생성합니다. 이슈는 **구현 전 기획서** 역할을 합니다.

## 작업 순서

### 1단계: 이슈 타입 선택

AskUser로 다음 내용을 질문:

```text
이슈 타입을 선택해주세요:

1. [Feature]: 새로운 기능 요청
2. [Bug]: 버그 리포트
3. [Refactor]: 리팩토링 제안
4. [Docs]: 문서 관련
5. [Chore]: 기타 작업
```

### 2단계: 이슈 제목 입력

AskUser로 다음 내용을 질문:

```text
이슈 제목을 입력해주세요:
(예: 사용자 인증 기능 추가)
```

### 3단계: 기능 개요 입력

AskUser로 다음 내용을 질문:

```text
이 기능/작업의 개요를 설명해주세요:
(무엇을 왜 해야 하는지)
```

### 4단계: 상세 요구사항 입력

AskUser로 다음 내용을 질문:

```text
상세 요구사항을 입력해주세요:
(구현해야 할 세부 기능들, 여러 줄 가능)
```

### 5단계: 라벨 선택 (선택사항)

AskUser로 다음 내용을 질문:

```text
라벨을 선택해주세요 (복수 선택 가능, 없으면 스킵):

1. bug
2. enhancement
3. documentation
4. question
5. help wanted
6. good first issue
7. 스킵
```

### 6단계: 이슈 본문 자동 생성

이슈 타입에 따라 **기획서 형태**의 템플릿 적용:

#### [Feature] (기능 요청) 템플릿
```markdown
## 개요

[사용자 입력 개요]

## 기능 요구사항

[사용자 입력 상세 요구사항을 정리하여 작성]

### 세부 기능
- [ ] 세부 기능 1
- [ ] 세부 기능 2
- [ ] 세부 기능 3

## 구현 가이드

- 관련 파일/컴포넌트:
- 참고 사항:

## 완료 조건

- [ ] 기능 구현 완료
- [ ] 테스트 통과
- [ ] 코드 리뷰 완료
```

#### [Bug] (버그 리포트) 템플릿
```markdown
## 개요

[사용자 입력 개요]

## 버그 상세

### 현재 동작
[현재 발생하는 문제]

### 예상 동작
[정상적으로 동작해야 하는 방식]

### 재현 방법
1.
2.
3.

## 수정 가이드

- 예상 원인:
- 관련 파일:

## 완료 조건

- [ ] 버그 수정 완료
- [ ] 재현 테스트 통과
- [ ] 회귀 테스트 확인
```

#### [Refactor] 템플릿
```markdown
## 개요

[사용자 입력 개요]

## 리팩토링 범위

[사용자 입력 상세 요구사항]

### 변경 대상
- [ ] 변경 항목 1
- [ ] 변경 항목 2

## 리팩토링 가이드

- 현재 구조:
- 목표 구조:
- 주의 사항:

## 완료 조건

- [ ] 리팩토링 완료
- [ ] 기존 기능 정상 동작 확인
- [ ] 테스트 통과
```

#### 기타 템플릿 ([Docs], [Chore])
```markdown
## 개요

[사용자 입력 개요]

## 작업 내용

[사용자 입력 상세 요구사항]

### 세부 작업
- [ ] 작업 항목 1
- [ ] 작업 항목 2

## 완료 조건

- [ ] 작업 완료
```

### 7단계: 이슈 미리보기 및 확인

생성될 이슈 내용을 미리보기로 보여주고 확인 질문:

```text
아래 내용으로 이슈를 생성할까요? (y/n)

---
**제목:** [타입] 이슈 제목
**라벨:** [선택된 라벨들]

[이슈 본문 미리보기]
---
```

### 8단계: GitHub CLI로 이슈 생성

```bash
gh issue create \
  --title "[타입] 이슈 제목" \
  --body "이슈 본문" \
  --label "라벨1,라벨2"
```

라벨이 없는 경우:
```bash
gh issue create \
  --title "[타입] 이슈 제목" \
  --body "이슈 본문"
```

### 9단계: 결과 처리

- 성공: 이슈 URL 표시 및 브라우저에서 열기 제안
- 실패 시 에러 메시지 표시

## 에러 처리

### gh CLI 미설치
```text
GitHub CLI(gh)가 설치되어 있지 않습니다.
설치: brew install gh
인증: gh auth login
```

### 인증 안됨
```text
GitHub 인증이 필요합니다.
실행: gh auth login
```

### 권한 없음
```text
이 저장소에 이슈를 생성할 권한이 없습니다.
저장소 권한을 확인해주세요.
```

## 참고사항

- 프로젝트 URL: https://github.com/silverbeen/silverbeen
- 이슈는 **구현 전 기획서**로 작성 (구현 완료 보고서가 아님)
- 이슈 생성 후 `--web` 옵션으로 브라우저에서 열기 가능
- Assignee 지정: `--assignee @me` 옵션 사용 가능
